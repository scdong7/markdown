| 参数            | 作用                       | 示例                                         |
| --------------- | -------------------------- | -------------------------------------------- |
| `-i`            | 忽略大小写                 | `grep -i "error" app.log`                    |
| `-n`            | 显示行号                   | `grep -n "ERROR" app.log`                    |
| `-v`            | 反向匹配，显示不匹配的行   | `grep -v "^#" nginx.conf`                    |
| `-c`            | 只统计匹配行数             | `grep -c "ERROR" app.log`                    |
| `-w`            | 整词匹配                   | `grep -w "port" config`                      |
| `-r`            | 递归搜索目录               | `grep -r "TODO" src/`                        |
| `-l`            | 只列出包含匹配的文件名     | `grep -rl "ERROR" logs/`                     |
| `-o`            | 只输出匹配到的内容         | `grep -o "192.168.[0-9.]*" app.log`          |
| `-E`            | 使用扩展正则               | `grep -E "error                              |
| `-F`            | 按固定字符串匹配，不用正则 | `grep -F "java.lang.Null" app.log`           |
| `--color=auto`  | 高亮匹配内容               | `grep --color=auto "ERROR" app.log`          |
| `--include`     | 只搜指定文件类型           | `grep -r "TODO" --include="*.java" src/`     |
| `--exclude-dir` | 排除目录                   | grep -r "TODO" --exclude-dir=node_modules .` |
