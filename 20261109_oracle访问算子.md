# 一、表、索引与其他数据访问算子

| **类别**   | **执行计划显示名称**                | **作用或说明**                          |
| ---------- | ----------------------------------- | --------------------------------------- |
| 表扫描     | TABLE ACCESS FULL                   | 全表扫描                                |
| 表扫描     | TABLE ACCESS SAMPLE                 | 抽样访问                                |
| 表扫描     | TABLE ACCESS SAMPLE BY ROWID RANGE  | 按 ROWID 范围抽样                       |
| ROWID 访问 | TABLE ACCESS BY USER ROWID          | 根据用户提供的 ROWID 访问               |
| ROWID 访问 | TABLE ACCESS BY INDEX ROWID         | 根据索引返回的 ROWID 回表               |
| ROWID 访问 | TABLE ACCESS BY INDEX ROWID BATCHED | 批量收集 ROWID 后，尽量按数据块组织回表 |
| ROWID 访问 | TABLE ACCESS BY GLOBAL INDEX ROWID  | 通过全局索引访问分区表                  |
| ROWID 访问 | TABLE ACCESS BY LOCAL INDEX ROWID   | 通过本地索引访问分区表                  |
| ROWID 访问 | TABLE ACCESS BY ROWID RANGE         | 按 ROWID 范围访问                       |
| 簇表访问   | TABLE ACCESS CLUSTER                | 通过索引簇访问                          |
| 簇表访问   | TABLE ACCESS HASH                   | 通过 Hash Cluster 键访问                |
| 索引扫描   | INDEX UNIQUE SCAN                   | 唯一键查找                              |
| 索引扫描   | INDEX RANGE SCAN                    | 索引范围扫描                            |
| 索引扫描   | INDEX RANGE SCAN DESCENDING         | 降序范围扫描                            |
| 索引扫描   | INDEX FULL SCAN                     | 按索引键顺序扫描整个索引                |
| 索引扫描   | INDEX FULL SCAN DESCENDING          | 降序扫描整个索引                        |
| 索引扫描   | INDEX FAST FULL SCAN                | 将索引作为较窄的数据源扫描，不保证键序  |
| 索引扫描   | INDEX SKIP SCAN                     | 跳跃扫描复合索引                        |
| 索引扫描   | INDEX FULL SCAN (MIN/MAX)           | 利用索引边界求最小值、最大值            |
| 索引扫描   | INDEX RANGE SCAN (MIN/MAX)          | 在受限范围内进行 MIN/MAX 优化           |
| 索引扫描   | INDEX SAMPLE FAST FULL SCAN         | 索引快速全扫描的抽样形式                |
| 域索引     | DOMAIN INDEX                        | 域索引访问，如部分全文、空间索引路径    |
| 固定表     | FIXED TABLE FULL                    | 扫描固定表                              |
| 固定表     | FIXED TABLE FIXED INDEX             | 利用固定表的特定访问路径                |
| 外部表     | EXTERNAL TABLE ACCESS FULL          | 扫描外部表                              |
| 外部表     | EXTERNAL TABLE ACCESS STORAGE FULL  | 具有存储层处理能力的外部表访问          |
| 远程访问   | REMOTE                              | 访问远端数据库                          |
| 常量数据源 | FAST DUAL                           | 无须实际扫描 DUAL 的常量表达式数据源    |

Oracle 官方通用表列出了主要表访问与索引扫描形式；其中 BATCHED 的含义是改善按块访问的聚集程度，12.2、18c 等文档已有明确计划示例。上述补充名称中，MIN/MAX、固定表、外部表等应继续以目标版本实测补齐版本属性。需要特别区分：

·TABLE ACCESS HASH 是 **Hash Cluster 访问**。

·INDEX FAST FULL SCAN 与 INDEX FULL SCAN 的有序性不同。

·DOMAIN INDEX 是扩展接口，不能仅凭这个名称判断内部使用哪一种算法。
